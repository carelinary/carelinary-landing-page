# TASK LIST — Pengembangan Landing Page Carelinary

## Sprint 1 — Dasar dan kolaborasi
- [ ] Pastikan seluruh anggota menerima undangan GitHub.
- [ ] Verifikasi `git remote -v` mengarah ke `carelinary/carelinary-landing-page`.
- [ ] Tambahkan demo website ini ke repository melalui feature branch dan Pull Request.
- [ ] Tentukan owner: marketing copy, desain UI, developer, dan reviewer klinis.

## Sprint 2 — Awareness
- [ ] Review hero headline, problem, negative consequences, dan segmentasi audiens.
- [ ] Pastikan tidak ada klaim penyakit yang berlebihan atau tidak berdasar.
- [ ] Finalisasi foto makanan, logo, dan tone brand.

## Sprint 3 — Consideration
- [ ] Validasi USP farm-to-table, chef profesional, dan kemasan ramah lingkungan.
- [ ] Konfirmasi ahli gizi yang akan menangani asesmen.
- [ ] Validasi paket GERD dan Cardiometabolic, nutrisi, alergen, dan SOP.
- [ ] Putuskan apakah health screening tersedia; jenis tes, partner, dan biaya.
- [ ] Hitung HPP, harga jual final, dan batas area pengiriman.

## Sprint 4 — Conversion
- [ ] Finalisasi paket 5/10 hari dan pilihan lunch/dinner.
- [ ] Tentukan sistem daftar minat: Formspree, Supabase, atau backend pilihan tim.
- [ ] Tambahkan consent, privacy policy, penyimpanan aman, dan anti-spam.
- [ ] Uji submission end-to-end, notifikasi admin, dan follow-up lead.
- [ ] Tambahkan analytics dengan consent sesuai ketentuan.

## Sprint 5 — QA dan Deployment
- [ ] Tes tampilan desktop, tablet, mobile.
- [ ] Tes keyboard accessibility, menu, FAQ, kalkulator, dan formulir.
- [ ] Optimalkan gambar dan performa loading.
- [ ] Review legalitas, klaim medis, dan izin usaha yang berlaku.
- [ ] Import repository GitHub ke Vercel, uji preview, lalu deploy production.
- [ ] Hubungkan `carelinary.my.id` setelah disetujui tim.
